## О проекте
**Online Store** — учебный проект на Python, представляющий ядро интернет-магазина. Проект демонстрирует работу с продуктами, категориями, заказами, абстрактными классами и утилитами для обработки данных. В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота. 

**Основные возможности:**
- Создание и управление продуктами и категориями
- Поддержка абстрактных классов для продуктов и заказов
- Итераторы для обхода товаров и категорий
- Миксины для печати информации о созданных объектах
- Чтение данных из JSON и их подготовка для классов

## Использование

1. Клонирование репозитория: 
```bash
git clone https://github.com/kshaab/Online-Store-SPA
cd crswrk_1
```
2. Установка зависимостей и активация виртуальное окружения:
```bash
poetry install
poetry shell
```
3. Запуск файла: 
python src/main.py

## Основной функционал

### 🔸 Products 

`class Product` 

Инициализирует продукт и его свойства.

### 🔸 Categories

`class Category` 

Инициализация категорий с продуктами, подсчет количества продуктов.

`class CategoryIterator`

Итератор для обхода товаров одной категории. 

### 🔸Product Heirs

`class Smartphone(Product)`

Добавляет свойства: efficiency, model, memory, color.

`class LawnGrass(Product)`

Добавляет свойства: country, germination_period, color. 

### 🔸 Order 

`class Order(BaseOrder)`

Содержит информацию о купленном товаре, количестве и стоимости.

### 🔸 Base Product 

`class BaseProduct(ABC)`

Абстрактный родительский класс для продуктов. 

### 🔸 Base Order 

`class BaseOrder(ABC)`

Абстрактный родительский класс для заказов и категорий.

### 🔸 Mixins

`class PrintMixin`

Выводит информацию о созданном объекте и его параметрах.

### 🔸 Utils 

`read_json(path)` 

Считывает данные из json-файла.

```python
>>> read_json("file.json")
{'products': [...], 'categories': [...]}
```

`get_products(file_data)` 

Формирует списки продуктов и категорий для классов.

```python
>>> get_products(data)
[Product(...), Product(...)]
```

### 🔸 Main

`main()`

Запускает основной сценарий работы программы.
